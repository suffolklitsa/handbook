# Other good resources

Where something good already exists, we link to it instead of rewriting it.

## GitHub and git

- **GitHub Skills** (skills.github.com): short interactive courses inside GitHub. Start with "Introduction to GitHub."
- **First Contributions** (github.com/firstcontributions/first-contributions): another walkthrough of a first pull request.
- **GitHub Docs: Hello World** (docs.github.com): repositories, branches and pull requests in one page.
- **The Missing Semester of Your CS Education** (missing.csail.mit.edu): MIT's lectures on the terminal, git and editors. Good once the basics click.

## AI coding tools

- GitHub Copilot documentation (docs.github.com/copilot)
- Claude Code and Codex: each has official documentation on its company's site. Use those over blog posts, which go stale fast.

## Legal tech

- The Suffolk LIT Lab and its Document Assembly Line project, for court forms and guided interviews
- Free Law Project (free.law), for open court data and tools like CourtListener
