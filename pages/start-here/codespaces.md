# Work in the browser with Codespaces

A Codespace is a full editor and terminal that runs in your browser, already set up for the repo you open it from. Nothing to install, and it works the same on a Mac, a PC or a library computer.

## Open one

1. Go to any LITSA repo, for example github.com/suffolklitsa/handbook.
2. Click the green **Code** button → **Codespaces** → **Create codespace on main**.
3. Wait a minute while it builds. You'll see an editor (it's VS Code) with the repo's files on the left and a terminal at the bottom.

## Find your way around

- **Files** are on the left. Click one to open it.
- **The terminal** is at the bottom. Each repo's README lists the commands to run there, such as the checks before a pull request.
- **Source control** (the branch icon on the left) shows what you've changed and lets you commit.
- **Copilot** appears once your Student Developer Pack is approved.

## Stop it when you're done

Codespaces use free monthly hours. Close the tab when you're finished, and it stops on its own after a while. You can see and delete old ones at github.com/codespaces.
