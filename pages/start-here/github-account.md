# Make a GitHub account and join the org

**Time:** about 15 minutes, plus a few days for the student pack to be approved.

## 1. Make an account

Go to github.com and sign up. Use a username you'd be comfortable showing an employer; it appears on everything you contribute. You can use a personal email and add your school email later.

Turn on two-factor authentication (Settings → Password and authentication). GitHub requires it for contributors, and it protects your work.

## 2. Apply for the GitHub Student Developer Pack

Go to education.github.com and apply with your Suffolk email. It's free for verified students and includes GitHub Copilot and more free Codespaces time. Approval can take a few days; you can start everything else meanwhile.

## 3. Join the suffolklitsa organization

Send your GitHub username to the LITSA president (sam.darkwa@su.suffolk.edu), or post it in the Build topic on the LITSA GroupMe. You'll get an email invitation; accept it from the email or at github.com/suffolklitsa.

You don't need to be in the org to contribute to public repos, but members can be assigned issues and see the [Build board](https://github.com/orgs/suffolklitsa/projects/1).
